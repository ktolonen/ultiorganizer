# Live! by BULA

[Live! by BULA](https://github.com/layoutd/live-by-bula) is an optional public
interface for Ultiorganizer. It presents live games, schedules, standings, team
information, Spirit scores, and player statistics in a modern,
mobile-friendly view.

Live! is developed and released separately. Its combined installation package
bundles a tested version of Ultiorganizer. The Ultiorganizer `master` branch may
be newer and may still work with Live!, but compatibility is not guaranteed.

## Installation

The upstream guide covers both new installations with the combined package and
adding Live! to an existing Ultiorganizer installation. It also covers
configuration, updates, and the required terms of use. Follow the instructions
in the [Live! by BULA repository](https://github.com/layoutd/live-by-bula).
